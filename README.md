# Student Performance Prediction

A machine learning project that predicts student performance using Python and Scikit-learn.

## 📌 Project Overview

This project uses student-related data to analyze performance patterns and build a machine learning model for predicting student performance.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 📂 Project Files

* `Student_performance_prediction.ipynb` — Jupyter Notebook containing data analysis, preprocessing, model training, and prediction.
* `Student_performance_dataset.csv` — Dataset used for the project.
* `README.md` — Project documentation.

## 🔍 Project Workflow

1. Load the dataset
2. Explore and understand the data
3. Clean and preprocess the data
4. Perform exploratory data analysis
5. Train the machine learning model
6. Evaluate the model
7. Predict student performance

## 🎯 Objective

The main objective of this project is to use machine learning techniques to analyze student data and predict academic performance.

## ▶️ How to Run

1. Download or clone this repository.
2. Open `Student_performance_prediction.ipynb` using Jupyter Notebook or Google Colab.
3. Make sure the dataset file is in the same folder as the notebook.
4. Run the notebook cells sequentially.
